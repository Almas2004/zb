# Абзал СРМ

Полноценный первый релиз CRM для внутренней работы по делам должников на основе листа `Сводник` из Excel-файла.

## Что входит

- React/Vite frontend: вход, список дел, создание, редактирование, карточка дела.
- Express backend: JWT-авторизация, CRUD API, расчет контрольных дат.
- PostgreSQL: хранение дел, контрольных дат, подтверждений и истории уведомлений.
- Telegram Bot API: напоминания в группу и inline-кнопка `Прочитал`.
- Seed из Excel: берутся только поля с `ДГД` по `Дата определения суда`; исключенные даты не используются.

## Бизнес-правила дат

Если `Дата определения суда` пустая, все автодаты пустые. При изменении даты суда контрольные даты пересчитываются, а подтверждения по измененным датам сбрасываются.

Рабочие дни сейчас считаются как понедельник-пятница. Модуль `server/src/dateRules.js` уже принимает список праздников, чтобы позже добавить официальный календарь.

Автоматические даты:

- `+2 рабочих дня`: дата направления в ДГД объявления и сопроводительного письма от ФУ.
- `+5 рабочих дней`: направить запросы в гос органы.
- `+10 рабочих дней`: ответы гос.органы.
- `+20 рабочих дней`: подготовить заключение.
- `+20 рабочих дней` от даты направления в ДГД: сбор от кредиторов реестра требований кредиторов.
- `+10 рабочих дней` от даты сбора: подача реестра требований кредиторов.

## Цвета контрольных дат

- Серый: до контрольной даты остался 1 день.
- Красный: дата наступила, подтверждения нет.
- Зеленый: дата наступила и нажата кнопка `Прочитал`.
- Нейтральный: дата в будущем или дата не рассчитана.

## Быстрый запуск

1. Установите зависимости:

```bash
npm install
```

2. Скопируйте env:

```bash
copy server\.env.example server\.env
```

3. Запустите PostgreSQL:

```bash
docker compose up -d
```

4. Инициализируйте базу и администратора:

```bash
npm run db:init
```

5. Загрузите данные из Excel:

```bash
npm run db:seed
```

По умолчанию seed ищет файл:

```text
C:\Users\anm24\Downloads\для Алмаса таблица по ФИН УПР..xlsx
```

Для другого пути:

```bash
set EXCEL_PATH=C:\path\to\file.xlsx
npm run db:seed
```

6. Запустите проект:

```bash
npm run dev
```

Frontend: http://localhost:5173  
Backend: http://localhost:4000  
PostgreSQL в Docker: `127.0.0.1:5433`

Логин по умолчанию:

```text
admin@crm.local
admin123
```

## Telegram

1. Создайте бота через BotFather.
2. Добавьте бота в Telegram-группу.
3. Заполните `server/.env`:

```env
TELEGRAM_BOT_TOKEN=123456:token
TELEGRAM_CHAT_ID=-1001234567890
APP_URL=http://localhost:5173
TELEGRAM_WEBHOOK_SECRET=long_random_secret
```

4. Для inline-кнопки `Прочитал` нужен webhook на backend:

```text
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://your-domain.com/api/telegram/webhook/<TELEGRAM_WEBHOOK_SECRET>
```

В локальной разработке можно использовать ngrok и указать публичный URL.

## Уведомления

Scheduler запускается каждый день по `NOTIFICATION_CRON` из `server/.env`, по умолчанию в 09:00. Дополнительно в интерфейсе есть кнопка `Проверить уведомления`, она вручную запускает тот же процесс.

Уведомления отправляются:

- за 1 день до контрольной даты;
- в день контрольной даты.

Повторные сообщения одного типа не дублируются благодаря таблице `notification_events`.
